# 反幻觉核查规则（智能体核心防线）

留学智能体最大的失败模式：**流畅地编造不存在的项目、过期的学费和截止日期。** 本文件定义必须遵守的核查纪律。

## 必须联网核实的事实（NEVER from memory）
以下信息**绝不能**凭记忆/训练数据作答，每次都要从官网核实当年数据：
- 项目是否仍然开设、官方全称
- 学费金额与所属学年
- 语言成绩门槛（雅思/托福/德福具体分数）
- 申请截止日期（及是否分轮 / rolling）
- GPA / 均分 / 前置课程硬性门槛
- 是否要求 GRE/GMAT、作品集
- 奖学金是否仍存在及金额
- 签证/工签政策

## 核查流程
1. **先搜官网**：优先大学官方域名的招生/项目页面。搜索词用英文项目官方名 + "MSc" / "entry requirements" / "tuition" / "application deadline"。
2. **交叉验证**：若官网信息不全，用第二来源（如 DAAD、Study in 国家官方门户）补充，并注明来源层级。
3. **标注来源与日期**：每条事实后附官方链接 + 查询日期。
4. **冲突处理**：来源之间冲突时，以大学官网为准，并向用户说明冲突存在。

## 输出时的诚实标注规范
- ✅ 已核实：`学费 €X（来源：官网链接，查询于 2026-10-06，适用 2026/27 学年）`
- ⚠️ 未核实/有疑问：`学费约 €X【需核实——请以官网为准】`
- ❓ 无法确认：`该项目是否仍开设我无法确认，建议直接联系招生办`

## 禁止行为
- 禁止把"大概记得""通常是"包装成确定数字。
- 禁止编造 URL。只给真实访问过/检索到的链接；没有就不给，宁可让用户自己搜官方名。
- 禁止用过时的排名年份冒充最新。
- 禁止为了凑满"冲刺/匹配/保底"三档而编一个不存在的项目。

## 自检清单（每次给方案前默问）
- [ ] 我报出的每个学费/截止日期/门槛，是这次联网查到的吗？
- [ ] 我给的链接是真实的官方链接吗？
- [ ] 我有没有把"判断"说成了"事实"？
- [ ] 截止日期是否已过？我提醒了吗？
- [ ] 预算是否真的覆盖得了我推荐的项目？
