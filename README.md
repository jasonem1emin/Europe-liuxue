# 欧洲研究生留学智能体 🎓🇪🇺

一个帮你根据**本科院校、专业、GPA、语言成绩、预算**等背景，给出**真实存在、当前有效、申请可行**的欧洲硕士选校与申请方案的智能体。

核心设计理念：**知识库负责方法论，联网核实负责事实，提示词负责纪律。** 专门针对留学建议最大的坑——AI 流畅地编造不存在的项目、过期的学费和截止日期——做了反幻觉约束。

## 目录结构
```
prompts/
  system_prompt_zh.md       # 【主指令】完整系统提示词（角色/铁律/流程/输出格式）
  one_paste_prompt_zh.md    # 【一键复制版】贴进任意联网模型即用
knowledge/
  anti_hallucination_rules.md  # 反幻觉核查规则（核心防线）
  europe_country_guide.md      # 欧洲各国留学体系方法论速查
templates/
  intake_form_zh.md         # 背景信息采集表
.claude/skills/eu-master-advisor/
  SKILL.md                  # Claude Code 可安装 skill（自动触发）
```

## 三种使用方式

**1. 最简单——复制粘贴。** 打开 `prompts/one_paste_prompt_zh.md`，整段复制到一个**支持联网**的 Claude 对话里，在末尾贴上你的背景信息即可。

**2. 完整版。** 把 `prompts/system_prompt_zh.md` 作为系统提示词，配合 `knowledge/` 下两个知识库一起喂给模型，效果最佳。

**3. 作为 Claude Code Skill。** 本仓库的 `.claude/skills/eu-master-advisor/` 已是一个可用 skill。在装有 Claude Code 的环境打开本仓库，直接说"帮我规划欧洲硕士留学"即可自动触发，智能体会读取指令+知识库并联网核实后给方案。

## 它会给你什么
1. **画像定位**——诚实评估你在欧洲申请体系中的竞争力。
2. **国家匹配**——按预算/语言/就业目标筛选最契合的国家。
3. **三档选校清单**（冲刺/匹配/保底），每项联网核实官网信息，含学费、门槛、截止日期、官方链接。
4. **行动时间线**——倒推关键节点。
5. **风险与替代方案**——提前暴露最大风险。


## 🌐 交互式网页（新增）

`web/` 下是一个交互式网页版规划台：

- **`web/index.html`** —— 可独立打开/部署的完整网页（本地双击、或丢到任意静态托管即可）。
- **`web/artifact.html`** —— 同一页面的 Claude Artifact 版（已发布为在线可交互页面）。

网页能做什么：
1. **交互式背景采集表**——院校/专业/GPA/语言/预算/目标，优先级可用 ↑↓ 排序，草稿自动存本地。
2. **实时生成专属指令**——右侧即时拼出一份为你定制、含反幻觉铁律的指令，一键复制，拿去**联网的 Claude** 跑真实选校方案。
3. **AI 初步评估**（仅在 claude.ai 的 Artifact 中可用）——页面内直接调用 Claude，给竞争力画像 + 国家匹配 + 策略建议。该评估**不联网**，因此刻意**不输出**具体项目名/学费/截止日期，避免幻觉——那部分交给生成的指令去核实。

> 设计上把"方向性建议"（可在页面内即时给）与"需联网核实的事实"（项目/学费/截止日期）严格分开，这正是整套系统的反幻觉原则在网页上的落地。

## ⚠️ 重要前提
- **务必在能联网的模型上使用。** 学费、截止日期、项目是否开设每年变动，离线模型只能靠记忆，极易出错。智能体被要求：凡无法核实的信息一律标注"【需核实】"。
- 智能体的建议是**决策参考**，最终一切以大学官网与招生办为准。它不承诺录取结果。
